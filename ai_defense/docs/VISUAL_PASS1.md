# 비주얼 개선 1차 — 3D 월드 + 전투 HUD (브랜치 `v2-3d`)

지시: 「AI 디펜스 v2-3D 비주얼 개선 1차 지시」 (2026-11-12). 이번 범위는 **일반 모니터의 3D 월드와 전투 HUD만**.
터치 기본 화면(P1)·그림 건설 화면(P1)·건설/피격 연출(P2)은 이 결과를 승인받은 뒤 순서대로 진행한다.
참고: 지시서가 말한 `DESIGN_SPEC.md`, `UI_PREVIEW.html`은 전달받지 못해, 지시서 본문 기준으로 설계했다.

## 디자인 (무엇을 왜)
| 문제 (지시서) | 디자인 결정 |
|---|---|
| 형광 초록 지형 | 채도를 낮춘 풀색 2단 + 큰 얼룩/작은 얼룩, 숲 바닥은 더 어두운 녹색, 성벽 뒤 마을은 돌바닥 |
| 너무 넓은 황토색 길 | 길을 판정 폭(4칸)보다 0.9칸 좁게 그리고, 어두운 흙 테두리 → 밝은 흙으로 부드럽게, 자갈 점. 색은 진한 흙색이라 흰 스켈레톤이 잘 보임 |
| 싼 티 나는 소품 | Fantasy Stylized Pack(사용자 제공)의 소나무·바위·풀숲 + KayKit 둥근 나무. 소나무 잎은 팔레트를 밝은 초록으로 바꿔 씀 |
| 공간의 의미 | 위쪽 출현 게이트 둘레 = 숲과 큰 바위(아이들 게임이라 묘지 대신), 아래 = 성벽·성문·마을. 길 = 그 사이 지그재그 |
| 칙칙함 (2차 피드백) | 풀·흙 색을 밝고 따뜻하게, 안개 끔, 하늘색 배경, 풀밭에 작은 꽃 점(흰·노랑·분홍·보라) |
| 성 쪽이 깨져 보임 (2차 피드백) | 성벽 조각을 원래 비율(2m)로 키워 이어 붙임(전에는 1칸마다 찌그러뜨려 들쭉날쭉), 성문 양옆 탑+깃발, 체크무늬 돌바닥 → 풀밭+모래 광장, 건물은 KayKit 한 세트(빨강·노랑·파랑 지붕) |
| 캐릭터·적 가독성 | 아군 발밑에 팀 색 원판+굵은 고리, 적 발밑에 어두운 빨강 원판. 이름표는 둥근 꼬리표, 체력바 테두리 |
| 카메라 | 조금 더 가깝게 (높이 17→15.5, 시야 45°→42°), 옅은 거리 안개로 깊이감, 따뜻한 햇빛 |
| HUD가 화면을 가로지르는 검은 띠 | 떠 있는 카드 4개(마을 HP·남은 시간·처치·에너지) + 테두리 있는 미니맵. 크기는 화면 높이에 비례 |
| 대화창 | 줄마다 카드, 맨 아래가 최신(팀 색 테두리), 왼쪽 팀 색 띠, **게임 속 3D 모델로 찍은 얼굴**(나·든든이도 실루엣 대신 실제 모습) |

## 구현 (어떻게)
| 파일 | 내용 |
|---|---|
| `src/survival/view/sv_ground.gd` (새) | 바닥 그림 한 장을 구움(1칸=8픽셀, 셰이더 없음, 평면 1개). 첫 실행 약 1.2초, 이후 `user://`에 저장한 그림을 다시 씀 |
| `src/survival/view/sv_world3d.gd` | 지형 다시 구성: MultiMesh 숲(12칸 묶음별로 나눠 화면 밖은 안 그림), 길가 돌·풀, 출현 게이트 바위, 성벽 이어 붙이기·성문·탑, 마을 모델 교체(위치·판정은 JSON 그대로), 조명·카메라, 성문 고리는 맞을 때만 번쩍 |
| `src/survival/view/sv_models.gd` | 에셋 묶음에서 이름으로 모델 꺼내기(`pack_item`), 소나무 잎 팔레트를 초록으로 바꾼 복사 재질(`green_item`, 원본 파일은 그대로), KayKit 모델 크기 맞추기, 유닛 발밑 원판 |
| `src/survival/view/sv_portraits.gd` (새) | 3D 모델 얼굴을 시작할 때 한 번씩 찍어 텍스처로 보관 (P1 터치 카드에서도 사용 예정) |
| `src/survival/view/sv_hud.gd` | 상단 카드·미니맵·대화창·배너·이름표 다시 그림 |
| `assets/3d/fantasy/` (새) | TreesPack.glb, RocksPack.glb (묘지·중세 마을 팩은 쓰지 않아 뺐음) |
| `assets/3d/kaykit/hex/` | 성탑·깃발·마을 소품·색 다른 집 등 KayKit(CC0) 모델 추가 |
| `tools/pack_inspect.gd`, `tools/pack_gallery.gd`, `tools/sv_world_shots.gd` (새) | 에셋 크기·삼각형 수 확인, 모델 미리보기, 구역별 스크린샷 |

## 바꾸지 않은 것
맵 길 모양, 웨이브·출현 수, 공격력·체력, 시간, 에너지 비용, AI 판단 규칙, 그림 규칙(선=벽, 동그라미·세모·번개=필살기),
터치 화면, `--td` 타워디펜스, `data/*.json`.

## 검증 (2026-11-12, 개발 PC GTX 1060, 모니터 39Hz)
- 테스트: 3D 서바이벌 73개, 기존 2D 타워디펜스 914개 모두 통과
- `--single` 모드 스크린샷: 전투 화면(구역 4곳+전경), 터치 화면 — 텍스트 겹침·잘림 확인
- 그리기 부담(1280×720): 그리기 호출 약 175~235회, 삼각형 약 5만~8만 개, FPS 33~40 (이 모니터는 39Hz라 그 이상은 측정 불가)
- exe 자가 점검: 전투 진입, 새 지형·HUD 표시 확인 (새 폴더 `build/AI디펜스_v2_3D_비주얼1차`)
- **부스 PC(UHD 730) 실측 전이므로 30FPS 보장이라고 말할 수 없음.** 나무가 많아 내장그래픽 확인이 꼭 필요

## 에셋 라이선스
- KayKit (CC0): 그대로 사용, 라이선스 파일 유지
- Fantasy Stylized Pack: 사용자 PC의 `Desktop/FantasyStylizedPack`에서 나무·바위 2개 파일만 가져옴. **폴더에 라이선스 파일이 없어 출처·재배포 조건 확인 필요** — 공개 저장소에 올리기 전에 확인할 것
